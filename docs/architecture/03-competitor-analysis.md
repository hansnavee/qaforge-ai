# Competitor Analysis — QAForge AI

| Competitor | Strength | Gap vs QAForge |
|------------|----------|----------------|
| BrowserStack | Scale, device coverage | No AI requirement→framework pipeline |
| Testim / Mabl | Self-healing UI tests | Narrower audit surface; less consulting-depth reports |
| Functionize | NLP-driven tests | Closed platform; weaker exportable enterprise repos |
| Playwright Codegen | Free, local | No multi-agent QA, no SaaS orchestration |
| Applitools | Visual AI | Visual-only; not a full QA engineer |
| QA consultancies | Deep expertise | Expensive, slow, non-productized |

## Moat

Agent orchestration + secure auth handoff + downloadable enterprise automation + multi-score quality OS.
