# UI Wireframes — QAForge AI

## Visual language

Cursor/Linear-inspired density. Dark and light modes. Deep slate + teal/cyan accent. Restrained motion (phase transitions, progress pulse).

## Screens

1. **Auth** — centered brand-forward login/signup
2. **App shell** — left nav: Projects, Executions, Reports, Test Cases, Automation, GitHub, Settings; org switcher; theme toggle
3. **Projects list** — status chips, last scores
4. **New Project wizard** — Details → Requirements → Framework → Review
5. **Execution live** — phase timeline, browser session viewer, Continue-after-login banner
6. **Report** — executive dashboard, score rings, findings, media, download center
7. **Automation** — framework tree preview, GitHub push modal
8. **Billing** — plan cards, usage meters
